# social-media-assets

Repositório público usado apenas como hospedagem de imagens para publicação automática de posts (Instagram Graph API exige `image_url` pública, não aceita upload de arquivo local).

Estrutura: `posts/{id-do-post}.jpg` — cada imagem corresponde a uma entrada em `fila-postagens.json` no projeto principal.

Sem conteúdo sensível aqui — apenas artes de posts já aprovados para publicação pública.
